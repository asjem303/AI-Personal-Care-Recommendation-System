## AI-Based Overall Personal Care Recommendation System

## Project Description

The Intelligent Personalized Personal Care Recommendation System is a machine learning-based application designed to provide users with personalized personal-care recommendations based on their individual needs, preferences, and characteristics. The system collects information such as skin type, hair type, skin and hair concerns, age group, lifestyle preferences, and personal-care goals. This information is processed and analyzed using machine learning techniques to identify suitable personal-care products and recommendations for the user.

Unlike a traditional product-search system, the proposed system analyzes the user's profile and provides personalized recommendations. The recommendation engine uses content-based filtering, feature matching, and similarity analysis to identify products and recommendations that closely match the user's requirements.

The system aims to make personal-care product selection simpler, faster, and more personalized by using machine learning.

## Objectives

* Provide personalized personal-care recommendations.
* Analyze user skin, hair, scalp, and lifestyle characteristics.
* Reduce trial-and-error in personal-care product selection.
* Apply machine learning and recommendation techniques.
* Provide an easy-to-use web-based recommendation system.

## Datasets

The project currently uses two datasets:

1. Personal Care User Dataset

This dataset contains 1,500 user records and 20 attributes including:

* Age
* Gender
* Skin Type
* Skin Concern
* Hair Type
* Scalp Condition
* Sleep Hours
* Water Intake
* Diet Type
* Stress Level
* Sun Exposure
* Exercise Frequency
* Climate
* Smoking
* Alcohol Consumption
* Current Routine Steps
* Recommended Skincare
* Recommended Haircare
* Lifestyle Recommendation

2. Hair Care Dataset

This dataset contains 1,500 records and 12 attributes related to hair and scalp conditions, including:

* Hair Type
* Hair Porosity
* Scalp Type
* Common Issue
* Likely Cause
* Symptoms
* Recommended Solution
* Suggested Treatment
* Treatment Frequency
* Severity Level
