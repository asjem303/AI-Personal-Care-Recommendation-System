# Datasets
This folder contains the datasets used for the AI-Based Overall Personal Care Recommendation System.

## Personal Care User Dataset
Contains 1,500 user records with 20 attributes related to skin, hair, scalp, lifestyle, and personal-care recommendations.

## Hair Care Dataset
Contains 1,500 records with 12 attributes related to hair type, hair porosity, scalp condition, common hair issues, symptoms, treatments, and recommended solutions.

These datasets will be used for data preprocessing, feature engineering, machine learning model development, and personalized recommendation generation.
